The CCN Net Lab's TA

A technical assistant for the team: it reads the nets' guides, write-ups and design documents, and runs Wolfram code in a sandboxed CCN Cloud kernel to show its results rather than recall them. Choose what it reads; the whole lab is about 200,000 characters.

The TA is an AI teaching assistant, reached through CCN Cloud. Its knowledge pack was built 25 November 2026, 23:28 UTC. Every number it quotes should come from the pack or from code it ran; the examination (50 questions, run by kernel/ta_exam.nb in GitHub ccn-net-lab) measures how well it keeps to that.

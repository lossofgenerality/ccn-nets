# CCN Nets

The published pages of the neural nets of Computational Classnotes, one folder per project and per net, for example `free-form/subjectnet/`.

Site: https://lossofgenerality.github.io/ccn-nets/

Only finished pages are placed here. They are built from the source in the private repository `ccn-net-lab` and the projects that use it; each page names the source commit and training run it was built from.
